## Installation and rollback boundary

Use the supplied cumulative COPY_TO_APP contents in the existing app root. Keep original folders; merge and replace matching files. The checked installer creates a separate code backup and refuses unfamiliar edits. A local ZIP/copy does not itself publish GitHub Pages. Do not clear browser data.
Rollback is code-only and does not erase user records. Once B15 is stored in a session, Favorite or wear entry, an older release without B15 cannot display that new ID; its existing guard preserves rather than deletes unfamiliar records. Keep an export before any downgrade.

No other shoes, unconnected shirts, jeans/T-shirts, classifier thresholds, source holds, preference training labels or explicit-rejection rules were changed. The older rejection-recurrence defect remains outside this addition.
