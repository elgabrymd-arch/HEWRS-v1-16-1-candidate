# HEWRS V1.23.3 — swipe navigation and wrap-around

This cumulative copy package keeps the existing phone card layout, the thumbnail set, and the shoe-15 correction. It adds horizontal swipe navigation on the live option card and circular next/previous navigation.

On a phone: swipe left for next option, swipe right for previous option. If you move forward from the last option, the next option is 1. If you move backward from the first option, the previous option is the last option. Arrow buttons remain available as a backup.
