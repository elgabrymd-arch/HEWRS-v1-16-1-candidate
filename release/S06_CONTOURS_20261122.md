# S06 shoulder and arm contour correction

## Reproduced defect

The owner's enlarged S06 screenshot shows a rectangular shoulder step and a
stair-stepped arm opening. The exact previously published runtime
`eedd8842c32e842479775df4fdabefd27d88f9ef00e9606b569cfd5f395769c0`
reproduces both defects. The earlier material correction changed texture RGB
while preserving source alpha; it could not repair these contour defects.

The suit assembler applies the inherited S05 neck-junction mask to S06. At
native columns 686 and 687, that mask changes the shoulder's first half-opaque
row from 460 to 455, creating a five-pixel reverse step. Separately, coarse
source alpha boundaries become more conspicuous after the approved arm pose.
The arm opening itself is intentional negative space.

## Implemented correction

`src/issue22-s06-contours.js` is installed only in the active V3 delivery.
It retains the immutable source descriptors and marks the S06-specific mask
variant explicitly. A separate decoded-mask cache keeps the shared S05 mask
unchanged for all other garments. S06 receives a continuous right-shoulder
transition within `[620,410,100,90]`, preserving the existing near-neck clipping.

After the existing pose and cuff stages, a bounded alpha filter regularizes
the shoulder, upper sleeve and arm-gap contours. Cloth RGB is not blurred.
New or partly covered boundary pixels obtain color from adjacent opaque cloth
in the same rendered garment, preventing the original bright matte specks from
surviving at the corrected edge. The correction fades out before native row
1180; the lower sleeves, hands, trousers and shoes remain unchanged.

All final-pixel changes are confined to the union of three rectangles:

| Region | Native x, y, width, height |
| --- | --- |
| Right shoulder mask transition | 620, 410, 100, 90 |
| Left shoulder and upper arm | 60, 460, 280, 720 |
| Right shoulder and upper arm | 660, 460, 300, 720 |

The original PNGs, material-PNG alpha, avatar, pose, existing fit modules,
wardrobe IDs, matching scores and saved-data formats are unchanged. The S06
picker is regenerated using the same correction module as the outfit renderer.
The six other Issue22 picker images remain byte-identical.

## Verification

The focused native regression compares six S06 cases across DS001, DS039 and
DS051, both tied and untied, with the exact pre-correction runtime. It requires
the original defect to be present, the corrected shoulder to have no abrupt
reverse step, the arm gap to remain transparent and in place, and every pixel
outside the declared regions to remain unchanged. It also checks exact opaque
fabric samples and S05/S13/B08 full-frame controls. Each case runs in a separate
process to release native canvas memory.

The locally reviewed correction reduced the shoulder's backward step from
five pixels to zero. The subpixel arm-boundary curvature metric fell from
0.4383/0.4663 to approximately 0.01294/0.01175. This metric checks contour
regularity; it is not a measure of fabric fidelity or owner visual approval.

Independent enlarged-image review found the targeted notch and broad arm-edge
steps corrected at practical scale. Fine raster stepping remains visible at
large magnification, and the existing source fabric retains its prior softness.
This change makes no new claim of photographic fabric fidelity or perfection.

Source preservation, active delivery reconstruction, the source-lock mutation
checks, and S06 material/picker identity checks pass locally. Chromium cannot
start in the local executor because its required singleton socket is blocked.
Actual Chromium/WebKit and publication verification must pass in GitHub CI
before merge and release completion are reported.

The retained HTML under `tests/fixtures/s06-contour-baseline.html` is an exact
native-renderer test fixture, not a supported historical browser application.
The focused test pins its HTML digest and compiled runtime digest explicitly.
